Generation details & performance

Automatic checks can make up to three corrections, within a ten-minute total limit. Every request is interpreted first. Technical checks and explicit preservation checks run even when design review is off. Other visual requirements remain yours to assess in the preview.

Visual feedback can request one CSS correction. It replaces the previous valid proposal only when the image comparison identifies a resolved problem and no regressions. If time or evidence is insufficient, the previous proposal is retained.

Preview preparation stops after 12 seconds if it cannot complete. Optional feedback is limited to 45 seconds for measurements or 90 seconds for images; a validated proposal is retained if that feedback is unavailable.
